# Accuracy by channel and model size

Generated by `python analysis/accuracy_table.py` from the committed per-task rows; the same values as the paper's Table 10 (size runs).

Size runs: Qwen3-4B to 32B, one RTX PRO 6000 per run, 100k-token KV cache, k = 3 questions per task, 200 tasks per size (100 HotpotQA and 100 2Wiki), the same tasks in every channel. Each cell is accuracy (% of questions answered correctly) and, in parentheses, the paired difference to A1 broadcast (channel minus A1, in points, over the same tasks; negative means less accurate) and its 95% bootstrap interval, resampling tasks. An interval that excludes 0 is a significant difference. Bold: the most accurate of A1 to C per model size.
